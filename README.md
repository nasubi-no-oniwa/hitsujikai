# 羊飼いの1日

ぎゅうぎゅうに流れてくる羊。子羊が来たら押して柵を開け、囲いへ入れる。大人はそのまま通す。羊の着ぐるみのおじさんは、指ではじく。1匹でもまちがえたら終わり。

遊ぶ：https://nasubi-no-oniwa.github.io/hitsujikai/

- `index.html` … ゲーム本体（1つのファイル）
- `database.rules.hitsujikai.json` … ランキングのルール。GitHub に上げると自動で ft-green の `hitsujikai` に反映（ほかのゲームのルールはそのまま）。リポジトリの Secrets に `FT_GREEN_SERVICE_ACCOUNT` が必要
- `test/rules-test.mjs` … ルールの試験（GitHub の上で試し用のデータベースを立てて試す）

## しくみ
- 押している間だけ柵が開く（パソコンはスペースキー）。羊のまん中が柵の入口を通ったとき、柵が半分以上開いていれば囲い、閉じていれば通過
- 柵は開き切る・閉じ切るまでに0.07秒かかる。分けた数が増えるほど流れは速く、すきまはせまくなるので、どこかでだれにも分けられなくなる
- おじさんは15匹目より後にたまに出る。おじさんの上から指を払うと、はじける（そのときは柵は開かない）。柵まで来たら終わり
- 失敗したら、その瞬間をスローで見せる。「失敗の瞬間を動画にする」で、直前3秒＋スロー＋結果の動画を作る（遊んだ回の記録から作り直す）。iPhone は「共有」から X アプリへ、パソコンは保存してから投稿
- 毎回、はじめに短い場面（子羊を入れる→大人を通す→おじさんをはじく）が流れる。タップでとばせる
- 称号：迷える子羊 → 見習い羊飼い（5匹）→ 柵番（15）→ 一人前の羊飼い（30）→ 牧場の若頭（50）→ 腕利きの羊飼い（80）→ 牧場主（120）→ 羊の神の手（170）→ 羊界の伝説（230）→ 人間仕分け機（300）→ 羊飼いの神（400）
- 隠し結末：タイトルの「牧場に出る」を横にずらすと「おじさんに任せる」が出る。押すと、着ぐるみのおじさんが代わりに分ける。人数は `hitsujikai/oji` に1人1つ、ランキングの一番上に出る
- 始めた瞬間にサーバーの時刻を `hitsujikai/runs/人` に書く。記録は、その時刻から「匹数×0.08秒−2秒」より前には載らない
- 消したい記録は、Firebase の `hitsujikai/hidden/人のID` に `true` を入れるとランキングに出なくなる
- Xに投稿：リンクは結果ごとのページ `s/匹数.html`（0〜150匹。151匹からは `s/150p.html`・`s/200p.html`…、おじさんは `s/oji.html`）。日本語以外で遊んだ人は英語の画像 `s/en/` を使う
- ランキングは上位100人だけ読む。今日の分は `ds`（日×1000000＋匹数）の順で読む
